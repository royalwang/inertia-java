Inertia Spring Boot starter

This dependency-only module contains no public runtime Java API. Its Maven dependencies bring in the Inertia auto-configuration and Spring MVC stack.

Define an io.inertia.core.InertiaConfig bean, use the typed InertiaResponse in enabled MVC controllers, and configure the optional HTTP SSR gateway and Vite assets. See the generated API documentation for inertia-core, inertia-spring-webmvc and inertia-spring-boot-autoconfigure.

The application owns authentication, business transactions and Node process supervision. The complete runnable example and English usage guide are in the project repository.
